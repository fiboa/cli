# Agent guidelines

Follow [CONTRIBUTING.md](CONTRIBUTING.md) and the [Development](README.md#development) section of
the README. In addition:

- Keep PR descriptions, review comments and replies short. Answer questions in a sentence or two,
  and don't repeat what the author already did.
- Write `#123` only for issues and PRs of this repository, `owner/repo#123` for others, and no `#` in
  front of other numbers.
- Measure or run the code instead of assuming how it behaves.
